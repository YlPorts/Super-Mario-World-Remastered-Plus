LANGUAGE PACKS / PAQUETES DE IDIOMA

English:
- Copy en.txt and rename it, for example fr.txt.
- Change @code and @name.
- Edit only the text on the right side of the first unescaped = sign.
- Keep the original English text on the left unchanged.
- Use \n for a line break and save as UTF-8.
- Restart the game. The language will appear in Options > Language.

Español:
- Copia en.txt y cámbiale el nombre, por ejemplo fr.txt.
- Cambia @code y @name.
- Edita solamente el texto a la derecha del primer signo = que no esté escapado.
- No cambies el texto original en inglés de la izquierda.
- Usa \n para un salto de línea y guarda el archivo como UTF-8.
- Reinicia el juego. El idioma aparecerá en Opciones > Idioma.
